# Gate 合约助手

Gate USDT 永续合约页面的 Tampermonkey 脚本，基于 Vite + vite-plugin-monkey，源码在 `src/`。

## 功能

- **登录后启用**：先确认下单区显示已登录的交易按钮，再读取持仓和启动功能。未登录或账号状态始终无法确认时静默退出；运行中退出登录会完整清理。登录后需刷新页面启用。
- **亏损提醒**：每 300ms 读取资产区所有仓位的“未实现盈亏”，低于 `-100 USDT` 时在页面顶部持续显示红色横幅，提醒注意止损，并以亮黄色加粗强调只做确定性高的行情。恰好亏损 100 USDT 不提醒，回到阈值内自动移除；横幅不显示具体账户金额，资产隐私隐藏时仍能提醒。
- **持仓盈亏平衡价**：浮动面板的数据区第一行显示当前合约持仓的盈亏平衡价。只有多仓或空仓时取对应开仓均价；双向持仓按合计未实现盈亏为零计算，不含本次委托、手续费和资金费。沿用面板原有显示条件。
- **加仓后盈亏平衡价**：在“开多后预估强平价”和“开空后预估强平价”紧下一行，分别显示“开多后盈亏平衡价”和“开空后盈亏平衡价”。每个方向独立模拟，保留另一方向的当前仓位，按多空持仓在同一价格全部平仓、合计盈亏为零计算，不含手续费和资金费。单向持仓时等于该方向加仓后的均价。
- **加仓后强平价预估**：在每个方向的均价下面增加一行预估强平价，按当前委托价、数量、保证金模式、杠杆和最新风险档位计算。支持已有仓位的逐仓及经典全仓（含双向）加仓。数值带 `≈`，悬停可查看假设；必要字段缺失时说明无法预估的原因。[调研、公式和限制](docs/liquidation-research.md)。
- **开仓后均价预估**：在“开仓”标签下填好价格和数量后，浮动面板显示“开多/开空后均价”，并在下方显示预估强平价。面板带有边框，覆盖在页面上，初始位置为 `top: 100px; right: 310px`，不占用下单区布局。按住顶部“合约助手”标题栏可拖动，拖动、窗口缩放及内容变化时限制在可视区域内。只显示已有仓位的方向，没有仓位时不显示。
- **隐私隐藏**：右侧开仓、下方仓位、右下角资产三个模块及“可用”余额行可按需完全隐藏（`opacity: 0`），鼠标移入或输入框聚焦时立即显示（显示无过渡，避免看不清时误点）。仓位栏“仅显示当前市场”前面提供“隐藏：开仓 / 仓位 / 资产 / 可用”四个开关，勾选的区域才隐藏，原有 GM 存储设置继续生效（默认全部不勾选，升级后新增的“可用”也默认不勾选）。仓位模块只隐藏数据区，标签栏、按钮和筛选行保持可见；只有鼠标移到数据区本身才显示，碰到开关不会露出仓位。资产隐藏整个 `.asset-container_new` 容器，包括标题栏、拖拽区、资产数据及底部按钮；保留布局，鼠标移入资产模块或内部控件聚焦时显示。“可用”开关独立控制 `#multiCurrencyMarginModeFuturesStep1` 整行内容，包括标签、金额和图标；保留行布局，只有悬停或聚焦该行才显示。纯 CSS 实现：开关状态挂在 `<html>` 类名上，模块用 `:has()` 识别。

### 均价计算

```
新均价 = (仓位数量 × 开仓均价 + 下单数量 × 委托价) / (仓位数量 + 下单数量)
```

仓位数量和下单数量都会先换算成币的数量：

| 单位 | 换算方式 |
|---|---|
| 币（如 WIF） | 直接使用 |
| 张 | × 合约乘数（`quanto_multiplier`，来自公开接口 `api.gateio.ws`） |
| USDT | 不支持，面板提示“不预估均价”。USDT 的含义（名义价值还是保证金）未经验证，算错会误导下单 |

### 盈亏平衡价计算

根据 [Gate 未实现盈亏公式](https://www.gate.com/help/futures/futures/22155/profit-and-loss-pnl-and-roe-calculation)，将多空合计盈亏设为零，可得：

```
盈亏平衡价 = (多仓数量 × 多仓开仓均价 - 空仓数量 × 空仓开仓均价) / (多仓数量 - 空仓数量)
```

数量统一为币。多空等量且开仓均价相同，显示“任意价格均平衡”；多空等量但均价不同，显示“无平衡价（锁盈／锁亏）”。计算结果不为正数时显示“无正数平衡价”；双向仓位数量仍在换算时显示“换算中…”。

### 页面读取方式

- 委托价：`.dealbox` 里数量框之前、离它最近的可见输入框。
- 数量：`input[name="f_order"]`，单位取自同一个 label 里的 `span.truncate`。
- 百分比数量：用滑块下单时数量框显示 `25%`，真实数量取自数量框下方的提示 `≈ 190,638 / 184,885 WIF`，绿色（`.font-add-color`）是开多数量，红色（`.font-dec-color`）是开空数量，两边分别计算。普通模式下这一行显示的是 USDT 成本，不读取。
- 仓位：同时支持“列表”视图（`table.position-table`）和“详情”卡片视图（按“数量”“开仓均价”标签取下一行的值）。
- 全部仓位未实现盈亏：资产区 `.asset-container_new` 中的 `span.underline-dotted` 标签“未实现盈亏”，读取同一行 `.order-right-trans-container` 的完整 USDT 金额；缺失、重复或格式异常时沿用结构校验和整体停用机制。

页面是 React 渲染，滑块等程序化修改不会触发 input 事件，所以每 300ms 轮询一次（结果不变时不重绘），手动输入时额外立即刷新。

### 安全约束

脚本运行在真实交易页面上，以下约束用来保证不干扰下单/平仓：

- **结构不对应即整体停用**：脚本依赖的每个元素都有校验（`src/core/guard.js` 的 `expect`）。启动前先只读校验一遍，全部对应才启动，最多等 20 秒；运行中每次读取都校验，不对应持续超过 3 秒（容忍切换合约/标签时的中间状态）即停用。停用会清除所有定时任务、监听、插入的节点、样式和隐私隐藏状态，页面恢复原样，并在顶部显示横幅说明原因。脚本自身抛出的非结构异常也直接停用。区分“结构不对应”和“正常缺省”：市价单没有价格框、没有仓位、不在百分比模式、“资金流水”“负债管理”标签页没有“仅显示当前市场”（Gate 会记住上次停留的标签页）等属正常，不会触发停用；“仅显示当前市场”只在选中“仓位”标签时要求存在，选中标签本身（`text-c-text-1`，必须恰好一个）也在校验范围内。未登录时静默不启用。
- **先读后写**：每次刷新先完整读取并校验，全部通过才写 DOM，不会基于读错的结构渲染。
- **只在“开仓”标签下预估**：开仓/平仓共用同一个下单区，平仓不改变均价，所以“平仓”标签下不显示。

- **不触发任何交易操作**：只读取页面、插入自己的节点和样式，不点击、不修改 Gate 的任何元素。
- **没有仓位不显示面板**：对应方向没有仓位时，开仓后均价就是委托价，没有信息量，所以面板整体隐藏。浮动面板的显示与隐藏不影响下单按钮位置。
- **空闲零开销**：没填数量时不读取仓位区。实测开启全部功能后主线程开销与不装脚本无差异，无长任务。
- **接口失败退避**：合约乘数接口失败后 30 秒内不重试。

## 常用命令

```bash
npm install
npm run dev     # 开发模式，由插件处理脚本安装与热更新
npm run build   # 构建 dist/gate-futures-helper.user.js，并复制到根目录
npm test        # 公式、字段解析及登录生命周期回归验证
```

根目录的 `gate-futures-helper.user.js` 就是可以直接安装的脚本。版本号只写在 `package.json` 里，构建时会自动写进脚本头。

## 排查问题

Gate 改版后如果读取失败：打开控制台，把日志级别设成“详细”（Verbose），过滤 `[均价预估]`，就能看到脚本实际读到的价格、数量、单位和仓位。

## 目录结构

```text
src/
├── main.js               # 入口：结构校验通过后启动各功能

│   ├── guard.js          # 结构断言、生命周期登记、整体停用与清理

├── config.js             # 常量（面板 id、轮询间隔、接口地址）
├── features/
│   ├── avgPreview.js     # 均价预估：轮询、计算、决定显示/隐藏

├── gate/
│   ├── contract.js       # 合约名解析、合约乘数、单位换算
│   ├── orderForm.js      # 读取下单区的价格/数量/单位
│   └── positions.js      # 读取仓位（列表 + 卡片视图）

│   ├── avgPanel.js       # 面板挂载与渲染
│   └── banner.js         # 停用提示横幅

```
