# 加仓后强平价预估调研

调研日期：2026-11-13。范围：Gate USDT 本位线性永续合约、页面已有仓位的同向加仓。脚本不下单、不改原有控件、不读取登录凭据、不访问私有接口。

## 官方依据

1. [合约预估强平价和合约破产价计算](https://www.gate.com/zh/help/futures/futures/27724/calculation-of-estimated-liquidation-price-and-bankruptcy-price-of-contracts)：逐仓按仓位保证金计算，全仓需排除当前合约浮盈亏、保留其他仓位维持保证金占用；双向全仓需要同时计算多空，不能独立套两个单向公式。强平价只供参考。
2. [维持保证金计算](https://www.gate.com/zh/help/futures/other/38042/maintenance-margin-calculation)及 [2025 年风险限额升级公告](https://www.gate.com/zh/announcements/article/46339)：按仓位价值分段累计维持保证金，不能将合约第一档费率用于所有规模。双向模式采用较大一侧的维持保证金，加上对冲头寸的预估强平费。
3. [起始保证金](https://www.gate.com/zh/help/futures/futures/22148)及[委托成本计算](https://www.gate.com/zh/help/futures/futures/22156/order-cost-calculation)：起始保证金包含按杠杆占用的保证金和预留平仓费，开仓费属于另外的成本。空仓预留平仓费按委托成本文档包含 `1 + 1 / 杠杆` 系数。
4. [Gate API v4 官方文档](https://www.gate.com/docs/developers/apiv4/en/futures/)：`contracts/{contract}` 提供合约乘数、标记价、公开 Taker 费率；`risk_limit_tiers?contract=...` 提供完整风险档位及 `deduction` 速算扣除数。均为无需认证的 GET 接口。本次已读取 BTC_USDT 的实际公开响应，确认存在上述字段。

## 采用的计算

数量先统一成币，记价格为 `P`、数量为 `q`、均价为 `E`、公开 Taker 费率为 `f`。

某一侧在价格 `P` 下的维持保证金：

```
MM(q, P) = q × P × 档位维持保证金率 - 速算扣除数 + q × P × f
```

档位由该价格下的仓位价值确定。接口档位必须递增、扣除数必须连续；不完整、不连续或超出范围时停止该项预估。

单边浮盈亏：多仓 `q × (P - E)`，空仓 `q × (E - P)`。
双向全仓的维持保证金：

```
MM_total(P) = max(MM(qLong, P), MM(qShort, P)) + min(qLong, qShort) × P × f
```

### 有效保证金的反推（脚本推导，并非 Gate 提供的预估接口）

脚本不持有完整账户资金快照。为保留当前保证金调整和其他仓位的影响，用 Gate 页面当前强平价 `P0` 校准：

```
M = MM_total(P0) - 当前合约浮盈亏(P0)
```

这来自强平边界的“有效保证金 + 浮盈亏 = 维持保证金”等式。全仓的 `M` 已隐含页面计算强平价时的其他仓位盈亏和维持保证金，不应再把“可用余额”重复加进去。页面强平价有舍入，反推也存在误差。逐仓如没有有效强平价，但有明确保证金字段，可直接使用该字段。

模拟一笔订单按委托价全部成交：

- 新数量与新均价按数量加权计算，多空分别模拟，不假定两个方向同时成交。
- 全仓：`M_new = M - 新开仓名义价值 × f`。初始保证金占用不是新增账户资金。
- 逐仓：`M_new = M + 新开仓名义价值 / 当前杠杆 + 预留平仓费`。开仓费由账户可用资金另付，不能再次从仓位保证金中扣除。计算时保留杠杆为共同分母，将保证金、预留平仓费和强平方程统一通分后再做最终除法，避免 3 倍等杠杆的循环小数尾差。
- 保留另一方向已有全仓仓位。另一方向若明确为逐仓，不纳入该全仓资金池。
- 求解 `M_new + 新持仓浮盈亏(P) - MM_new(P) = 0`。梯度维持保证金连续且凸，权益线性，安全区间连续；按风险档位分别解线性方程，并校验解所属的档位及零保证金分支；以当前标记价区分上下边界，支持两个边界，避免二分近似尾差。
- 所有金额和数量通过字符串进入小型库 big.js，加减乘保持十进制精度，除法按数量级动态扩展小数位，至少保留约 100 位有效数字。加仓后保留总成本，避免加权均价的除法尾差再次影响盈亏。价格显示统一按有效小数截断，不四舍五入。

## 显示及限制

- 在每个方向的均价下方显示 `≈` 预估价；悬停说明保证金模式、公开费率和假设。仍沿用原有“无对应仓位不显示、平仓不显示、USDT 数量不预估”的行为。
- 账号检测先于结构校验、持仓读取、接口请求和 DOM 修改。状态未知时不启动；确认未登录时静默退出。运行中明确退出登录会移除脚本所有界面、监听和任务，并恢复被隐藏的内容。
- 使用最新读取到的页面仓位和强平价；公共标记价、费率、风险档位最多缓存 30 秒，过期后等待新数据，不沿用过期值。接口失败退避 30 秒。
- 这是基于当前快照的条件预估，未模拟其他市场未来波动、资金费、实际滑点、部分成交、其他委托成交或保证金自动追加；也不判断资金是否足够实际开仓。公开费率可能不同于账户 VIP/折扣费率和实际成交类型。
- 无法确认保证金模式、当前杠杆、当前强平价/逐仓保证金、另一方向数据，或双向全仓强平价明显不一致时，只显示不可预估原因。组合/多币种保证金不套用本模型。
- 风险档位范围内找不到边界时明确显示该情况，不能解释为永远不会强平。当前标记价已不满足维持保证金条件时显示提示。
- 本次浏览器工具返回 native pipe / browser host 不可用，未能核实用户 Edge 的实际 DOM，也未做真实交易页安装验证。页面字段使用当前仓库的结构约定及中文标签读取，需在真实页面确认兼容性。
